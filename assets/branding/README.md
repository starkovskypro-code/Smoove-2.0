# Иконка Smoove

Smoove-source.png — оригинал пользователя, 2048×2048, прозрачный фон.
Smoove.png — квадратный мастер 1024×1024 с полями для Windows.
Smoove.ico — размеры 16, 20, 24, 32, 40, 48, 64, 128, 256 px.
Smoove-*.png — отдельные размеры для будущего установщика и других поверхностей.

В ICO используется исходный рисунок без перерисовки. Для будущего установщика задайте Smoove.ico как его иконку; сам установщик пока не создан.
