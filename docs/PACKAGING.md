# Размер и упаковка Smoove — локальная оценка

Дата: 10 октября 2026. Цель — минимальный размер на диске без потери функций; число файлов вторично. Измерения ниже — логическая сумма файлов, не физически занятые кластеры файловой системы.

## Измеренные варианты Windows x64

| Вариант | Размер файлов, байт | Примечание |
|---|---:|---|
| Рабочая out/app до оптимизации | 369 888 682 | Общий Windows App SDK, ReadyToRun, отладочные файлы |
| Общий SDK без ReadyToRun и символов | 323 873 854 | Функции не удалены |
| Только пакет WinUI и его необходимые зависимости | 270 899 811 | Автономная папка до очистки диагностического EXE |
| Финальная локальная папка 0.5.0-rc.1 | 270 695 111 | Все runtime включены, инструкция включена, диагностический EXE исключён |
| Та же версия с внешними runtime | 38 258 244 | Это не автономная программа |

Локальный архив `out/release/0.5.0-rc.1/Smoove-0.5.0-rc.1-win-x64.zip`: **107 699 984 байта** (исторический эксперимент упаковки). Внутренний `Smoove.Settings.exe`: **336 896 байт**; отдельно от остальных файлов он не автономен.

Папка release не требует скачивания .NET/Windows App SDK. После распаковки нет дополнительного кэша распаковки Smoove на каждом запуске. Во время работы Windows/.NET могут создавать системные кэши; пользовательские настройки и backup находятся в `%LOCALAPPDATA%/Smoove`. Их объём зависит от исключений, на чистой машине общий расход не измерен. Если хранить скачанный ZIP рядом с распакованной папкой, логическая сумма — **378 395 095 байт**, плюс настройки и системные кэши.

## Почему размер сократился

Общий Microsoft.WindowsAppSDK заменён официальным Microsoft.WindowsAppSDK.WinUI 1.8.260803003 — той же версией WinUI, которая входила в исходный общий пакет 1.8.260921001. Транзитивные зависимости сохраняются автоматически; не используемые AI, ML, DirectML, ONNX и Widgets больше не включаются. Для framework-dependent публикации отдельно подключается Microsoft.WindowsAppSDK.Runtime.

ReadyToRun выключен: вместо увеличенных предварительно скомпилированных сборок используется JIT. Это не удаляет функции, но может увеличить время первого запуска; сравнительный benchmark не проведён. Trimming не включён: WinForms/WPF и UI Automation в текущей архитектуре не позволяют считать агрессивное обрезание безопасной настройкой. Файлы runtime вручную не удалялись.

## Практический выбор

- **Автономная папка/установщик:** рекомендованный текущий вариант. Установщик доставляет те же библиотеки; сжатие уменьшает скачивание, но не установленный объём. Локальный Inno Setup установщик rc.2 создан и проверен, подробности ниже.
- **Один автономный EXE:** поддержанная конфигурация WinUI включает PublishSingleFile и IncludeAllContentForSelfExtract. Она распаковывает зависимости и не экономит установленный объём; одновременно могут храниться и контейнер, и распаковка. В этой работе не собиралась после уточнения приоритета размера на диске.
- **Внешние runtime:** файлы приложения около 38 МБ, плюс .NET Desktop Runtime 10 x64 и Windows App Runtime 1.8 x64 совместимых версий. На текущем ПК .NETCore.App 10.0.12 занимает 80 006 873 байта, WindowsDesktop.App 10.0.12 — 98 957 096 байт, последний установленный Windows App Runtime x64 — 106 041 701 байт. Сумма с приложением — 323 263 914 байт, без прочих возможных компонентов и кэша установки. Эти runtime могут разделяться с другими приложениями; сравнение на новом ПК не выполнено. Размер скачивания установщиков не измерен. Первый framework-dependent прогон потребовал явного PackageReference на Runtime; после его добавления сборка прошла. Запуск этого варианта не проверен.
- **Переписывание на C++/Win32:** приложение в несколько мегабайт правдоподобно (ориентир 2–10 МБ, оценка), но это замена интерфейса и перенос host, UI Automation, настроек, трея, жизненного цикла и проверок. При сохранении WinUI остаются его крупные зависимости. Риск регрессий высокий; ради размера без отдельного решения пользователя не выполняется.

2–5 МБ автономно с текущим стеком не является реалистичной целью. 271 МБ — проверенное уменьшение, не доказанный абсолютный минимум.

## Проверки и границы готовности

Из распакованного локального архива прошли Test-Settings.ps1: пять ползунков, навигация, сохранение и чтение после перезапуска. Через опубликованную Smoove.Probe.dll прошёл native-набор: обе оси, отпускание Shift, движение мыши, начало жеста, частоты, ускорение и 96 000 единиц free-spin. TrayActivation с уведомлением трея и InvokePattern подтвердил восстановление свёрнутого и перекрытого окна; физический клик по значку этим не проверен.

Основной settings.json совпал по SHA256 с копией до проверок; backup восстановлен отдельно. Предыдущие незакоммиченные изменения сохранены. Кандидат включает текущее рабочее дерево, не соответствует опубликованному tag; локальное имя rc.1 не означает стабильный релиз. Чистая Windows без SDK/runtime, переустановка/удаление, реальные устройства и все программы не проверены. Подпись издателя отсутствует; GitHub не обновлялся.

Основа: [self-contained Windows App SDK](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/self-contained-deploy/deploy-self-contained-apps), [single-file WinUI](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/unpackage-winui-app#single-file-exe), [single-file .NET](https://learn.microsoft.com/en-us/dotnet/core/deploying/single-file/overview). Страницы Microsoft расходятся в общей формулировке поддержки single-file; установленный SDK содержит WindowsAppSDKSingleFileVerifyConfiguration, специальная страница описывает необходимые параметры.

## Стандартный установщик

`installer/Smoove.iss` и `scripts/Build-Installer.ps1` создают автономный установщик Inno Setup 7.1.0. Для выпуска `1.0.0` установка идёт для текущего пользователя; по умолчанию используется `%LOCALAPPDATA%\Programs\Smoove`, мастер позволяет выбрать другую папку. Создаётся ярлык в «Пуске», ярлык рабочего стола предлагается как задача. Установщик доступен на русском и английском, регистрирует удаление и запускает приложение после мастера. Все runtime включены, внешних загрузок нет.

Установщик проверяет mutex работающего Smoove: перед обновлением или удалением программу нужно завершить через трей. Удаление сохраняет пользовательские настройки и удаляет только запись автозапуска с точным путём этой установки. При обновлении записи beta старый путь переносится, только если команда указывает на `Smoove.Settings.exe --startup`.

Для релиза 1.0.0 используется `Smoove-1.0.0-Setup-win-x64.exe`; окончательные размер и SHA256 вносятся ниже после сборки из слитого коммита `main`. Инсталлятор пока не подписан сертификатом издателя, поэтому Windows может показать SmartScreen.

Проверка `tests/ui/Test-Installer.ps1 -Installer <полный путь>` установила программу в изолированную выбранную папку на D:, проверила полный runtime, реальные файлы ярлыков и запуск через ярлык рабочего стола, повторную установку, сохранение настроек и удаление файлов/ярлыков/автозапуска. Исходная запись автозапуска восстановлена. Логи — `out/installer-check/`; видимая страница выбора папки осмотрена на `wizard-directory.png`. Первый прогон остановился на ошибочном ожидаемом имени группы теста: установщик корректно создал группу Smoove, а не Smoove Installer Check; ожидание исправлено, тестовая установка удалена, полный повторный прогон прошёл. Проверка на отдельной чистой Windows, после входа в систему и с ограничениями корпоративной политики не проведена.

## Релиз 1.0.0

Релиз собирается только из чистого `main` командой `scripts/Publish-Release.ps1 -Version 1.0.0`. Скрипт создаёт автономный Inno Setup EXE и SHA256SUMS. В GitHub Release прикладывается только установщик и контрольная сумма; ZIP приложения не публикуется. Source code архивы GitHub автоматически создаёт для тега.

При переходе с beta тестируется миграция только распознаваемого значения автозапуска `Smoove.Settings.exe --startup`. Настройки остаются в `%LOCALAPPDATA%\Smoove`. На компьютере с личными ярлыками тестируй установщик с отдельным именем Start-группы и `-SkipDesktopShortcut`, чтобы их не перезаписывать.
