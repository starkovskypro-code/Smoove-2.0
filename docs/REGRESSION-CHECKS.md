# Повторный разбор после отказа пользовательской проверки

До изменений, 9 октября 2026: живые счётчики запущенного Smoove показали Wheel hook=526, injected=526, extra=0, accepted=0, sent=0. Утилита целиком пропускала источник колеса пользователя. Вторая подтверждённая ошибка: Telegram и большинство программ намеренно исключались из допуска. Успешные прежние проверки имели специальный injected test-marker и не воспроизводили источник пользователя.

Критерии этой правки, определённые до реализации:

- [x] Обычный маршрут принимает wheel с Windows injected-флагом и extra=0, как в реальных счётчиках пользователя; тестовая ветка фильтра удалена.
- [ ] Свои выходные события не преобразуются повторно. Сумма движения завершённого жеста сохраняется; пауза и отказ не оставляют продолжающуюся отправку.
- [ ] Telegram и другие доступные пользовательские программы проходят общий маршрут без списка из трёх браузеров. Доступ по уровню прав и защищённому desktop не обходится.
- [ ] Серии с интервалами 50/100/200 мс и дрожанием указателя не сбрасывают движение на каждом шаге; проверяются форма скорости, пропуски, отмены и реальная перерисовка.
- [ ] Native receiver показывает промежуточное движение между исходными шагами, а не просто большое число входных сообщений. Проверка содержит отрицательный контроль с отключённым сглаживанием.
- [ ] Яндекс Браузер на локальной fixture принимает тот же zero-extra injected источник обычной веткой. Сравниваются исходный и преобразованный ввод; измеряются смещение и его изменения по кадрам.
- [x] Telegram проверен в текущей переписке без отправки сообщений: raw 12 изменений/−252 px, smoothing 105 изменений/−249 px.
- [ ] Опубликованный exe из финальной папки проходит проверки, имеет видимую версию сборки и открыт для проверки реальной мышью пользователя. Непроверенные приложения не объявляются универсально совместимыми.

Команды и фактические результаты будут записаны после выполнения. Завершение автоматических тестов не заменяет пользовательскую приёмку ощущения скольжения; статичный скриншот не доказывает характер движения.
