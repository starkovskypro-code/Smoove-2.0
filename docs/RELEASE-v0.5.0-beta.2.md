# Smoove 0.5.0-beta.2 — What's new

Изменения относительно **0.5.0-beta.1**, предыдущего релиза и прежней версии main.

## Новое

- **Плавная горизонтальная прокрутка через Shift + обычное колесо.** Вниз — вправо, вверх — влево. Скорость, ускорение, сглаживание, разгон, инерция и частота общие с вертикальной осью. Каждая ось сохраняет своё движение; отпускание Shift не обрывает горизонтальную инерцию.
- **Отдельный плавный путь для файловой области Проводника.** Поддержаны сгруппированные папки, включая «Загрузки», Корзина и разные виды файлов. Размер плитки больше не увеличивает скорость: расстояние щелчка нормализовано с учётом масштаба Windows. Добавлен горизонтальный режим «Список».
- **Фирменная иконка Smoove** в трее, EXE и заголовке настроек. Подготовлены ICO и PNG для будущего установщика.

## Исправления прокрутки

- Убрана ошибочная отмена при движении мыши больше 8 px. Можно двигать курсор внутри окна и одновременно крутить колесо; инерция сохраняется.
- Исправлены потери первых щелчков при задержках окна настроек, повторном применении тех же настроек и обновлении маршрута.
- Замена дочернего окна страницы, например при загрузке видео, больше не отбрасывает остаток движения.
- Исправлена гонка времени при поступлении нового импульса во время обработки очереди. Начало движения стало отзывчивее без скачка позиции.
- Изменение параметров сохраняет текущую траекторию. Пауза и изменения исключений по-прежнему останавливают её.
- Исправлен выбор оси при Shift в приложениях, повторно переключающих направление колеса, как Figma. Шаги сохраняют выбранное направление при отпускании клавиши.

## Обновлённые настройки

- Раздел «Прокрутка» переименован в «Настройки»; тема оформления перенесена на основную страницу.
- Стартовый размер окна — 800 × 1120 px, ограниченный рабочей областью экрана; окно открывается по центру. При необходимости доступна прокрутка.
- Настройки структурированы в две колонки; «Точность движения» и «Тема оформления» расположены рядом с выровненными заголовками.
- Внутренние отступы — 64, расстояние между секциями — 48; подписи и значения разделены, чтобы не перекрываться.
- Частота обновления всегда видна. Сброс стал кнопкой-иконкой, центрированной относительно заголовка и подзаголовка.
- Компактные переключатели, кнопки удаления и сброса с иконками 18 px и областью нажатия 44 px. Удалён нижний блок; выход остаётся в трее.

## Скачать и обновить

В **Assets** скачайте **Smoove-0.5.0-beta.2-win-x64.zip**. Завершите Smoove через трей, распакуйте новый архив целиком в новую папку и запустите **Smoove.Settings.exe**. Пользовательские настройки сохраняются.

.NET и Windows App SDK включены. Windows 11 x64; права администратора для обычной работы не нужны. Это переносимая beta без установщика, автозапуска и автообновления; EXE не подписан. **SHA256SUMS.txt** содержит контрольную сумму архива.

## Проверки и ограничения

Проверены модель движения, полный native-набор (старт, движение мыши, обе оси, отпускание Shift, развороты, частота и free-spin), фактическое горизонтальное/вертикальное движение локальной страницы Яндекс Браузера. В Корзине семь видов дали одинаковое расстояние одного щелчка около 80 px при текущих системных настройках; проверены промежуточные позиции провайдера. Это не гарантия FPS.

Реальный холст Figma после последнего исправления не проверен. Повторная проверка Проводника в одном горизонтальном виде не подтвердила движение файлов; этот сценарий остаётся ограничением beta. UIA-провайдер занятого Проводника может задерживать движение. Совместимость со всеми приложениями, масштабами экрана и расширениями Shell не подтверждена. Физическое горизонтальное колесо остаётся исходным. Повышенные процессы и защищённые экраны не сглаживаются.
