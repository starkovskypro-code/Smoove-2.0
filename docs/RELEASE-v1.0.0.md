# Smoove 1.0.0 — первый стабильный выпуск

Smoove объединяет щелчки колеса в одно движение с регулируемым разгоном, инерцией и остановкой.

## What's new

- **Установщик Windows.** Выбор папки, установка для текущего пользователя, ярлык в меню «Пуск» и необязательный ярлык рабочего стола. .NET и Windows App SDK включены, скачивать зависимости отдельно не нужно.
- **Обновление и удаление.** Установщик обновляет прежнюю папку, сохраняет настройки и регистрирует приложение в списке установленных программ.
- **Автозапуск по выбору.** Переключатель в настройках запускает Smoove в трее при входе в Windows. При обновлении beta распознанная запись переносится на установленный путь.
- **Окно и трей.** Вызов восстанавливает свёрнутое окно и выводит настройки поверх окон текущего виртуального рабочего стола.
- **Блокнот.** Для RichEdit плавное движение синхронизирует текст и видимую полосу прокрутки.
- **Меньший размер программы.** Удалены неиспользуемые компоненты Windows App SDK, ReadyToRun отключён без удаления функций.

Сохранены возможности beta.2: общая модель вертикальной прокрутки и Shift+колеса, настройка скорости и инерции, free-spin без искусственного ограничения, исключения по пути EXE, плавный путь файловой области Проводника, нативные WinUI-настройки и меню трея.

## Установка и обновление

Скачайте **Smoove-1.0.0-Setup-win-x64.exe** из Assets. Запустите установщик, выберите папку и завершите мастер. По умолчанию Smoove устанавливается в `%LOCALAPPDATA%\Programs\Smoove`. Можно добавить ярлык на рабочий стол; ярлык в меню «Пуск» создаётся всегда.

При переходе с beta завершите переносимую копию через «Выход» в трее. Установщик перенесёт распознанную запись автозапуска `Smoove.Settings.exe --startup` на установленный путь. После проверки прежнюю переносимую папку можно удалить.

## Совместимость и ограничения

Предназначено для Windows 11 x64. Установщик не подписан сертификатом издателя, Windows может показать SmartScreen. Повышенные процессы, UAC, защищённые экраны и игры с античитом не заявлены как поддерживаемые. Плавность зависит от приложения. Реальный холст Figma и отдельный горизонтальный вид Проводника остаются неподтверждёнными сценариями. Автообновления нет.

Проверены установка в выбранную папку, ярлыки, запуск, повторная установка с сохранением настроек и удаление. Проверены трей, восстановление окна и виртуальные рабочие столы, движение в Блокноте, браузере, Telegram и Проводнике. На отдельной чистой Windows проверка не проводилась.
