# Smoove 1.0.1 — актуальная portable-сборка

## What's new

- Добавлен общий ползунок **«Темп анимации»** с диапазоном 0,5–4×.
- Темп ускоряет или замедляет всю существующую анимацию, сохраняя расстояние на щелчок и характер движения.
- Вертикальная и горизонтальная прокрутка используют общий темп.
- Изменение темпа во время движения сохраняет текущую позицию и фазу торможения.
- Обновлены README, руководство пользователя и скриншот панели настроек.
- В репозиторий и релиз добавлено видео демонстрации работы Smoove.

## Установка

Скачайте `Smoove-1.0.1-win-x64.zip` из Assets, распакуйте архив и запустите `Smoove.Settings.exe`. Установка в Windows не требуется; настройки хранятся в `%LOCALAPPDATA%\Smoove`.

Сборка предназначена для Windows 11 x64. Архив self-contained и содержит необходимые библиотеки .NET и Windows App SDK.
