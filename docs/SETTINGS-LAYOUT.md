# Правки настроек по скриншотам — 10 октября 2026

Раздел «Прокрутка» переименован в «Настройки» в навигации и заголовке. Тема оформления перенесена со страницы исключений на основную страницу. Нижний блок SMOOVE/подпись/Выход удалён; выход доступен из трея.

После первого варианта пользователь уточнил компактность: ширина старта 800 px, высота 900 px с ограничением доступной областью дисплея и центрированием. Возвращена вертикальная прокрутка. Внутренний Margin=64, расстояние между секциями и колонками 48. Это WinUI effective pixels для содержимого; AppWindow размер задаётся физическими пикселями Windows.

Скорость и плавность/инерция размещены в двух колонках, как разрешил пользователь. Точность и оформление размещены в отдельном общем ряду Grid с заголовками на одной высоте. Настройка частоты всегда раскрыта; Expander удалён. Сброс параметров движения — кнопка-иконка справа от заголовка с доступным названием и ToolTip «Сбросить настройки», показывается только в «Настройках».

Карточки исключений: toggle Width=40/MinWidth=0, действия центрированы по вертикали и разделены 12 px. Корзина — кнопка 44×44, Fluent glyph 24×24, normal Background/BorderBrush Transparent. Hover/pressed/focus используют штатный WinUI Button template и системные ресурсы. Доступные названия/подсказки сохранены. На малой ширине подписи параметров переносятся в выделенной колонке, значения занимают отдельную Auto-колонку.

Проверено: self-contained Release publish без ошибок/предупреждений; пять native Slider, навигация, сохранение и чтение после перезапуска через Test-Settings.ps1. Снимки работающего интерфейса: out/compact-settings.png (исключения), out/compact-settings-main.png (настройки). Визуально проверены два столбца, отсутствие перекрытий, общий ряд заголовков и положение сброса/карточек. Пользователь мог изменить высоту уже запущенного окна; код начального размера остаётся 800×900.

Отдельно не проверялись все DPI/системные размеры текста и динамический hover в карточке. При уменьшении окна сохраняется вертикальная прокрутка. Настройки/движок скролла не менялись. Исправления пока локальные и в рабочей ветке; публичный beta.1 ZIP не обновлён.
