# Как пользоваться Smoove

## Первый запуск

Если скачан установщик **Smoove-…-Setup-win-x64.exe**, запустите его, выберите папку на нужном диске и нажмите «Установить». По умолчанию используется `%LOCALAPPDATA%\Programs\Smoove`. Ярлыки появятся в «Пуске» и на рабочем столе; в конце мастер предложит запустить Smoove. .NET и Windows App SDK входят в установщик, скачивать дополнительные библиотеки не требуется. Установка выполняется для текущего пользователя. Для защищённых папок, например Program Files, могут потребоваться права, поэтому выбирайте доступную пользователю папку.

Библиотеки .NET и Windows App SDK входят в установщик. Сборка предназначена для Windows 11 x64 и не подписана сертификатом издателя.

При обновлении установленной версии завершите Smoove через «Выход» в трее и запустите новый установщик. Он использует прежнюю папку; пользовательские настройки сохраняются. Удаление доступно в Windows «Параметры → Приложения → Установленные приложения → Smoove». Перед удалением завершите программу. Удаление убирает ярлыки и автозапуск, если он указывает на эту установку; настройки в `%LOCALAPPDATA%\Smoove` сохраняются.

При переходе с переносимой beta 0.5.0-beta.2 завершите её через трей. Установщик переносит запись автозапуска, если она указывает на Smoove с параметром `--startup`. После проверки установленной версии прежнюю папку beta можно удалить.

Проверьте длинную страницу браузера и привычную переписку. Рекомендуемые настройки: **расстояние 1×, ускорение 60%, сглаживание 110%, частота 240 Гц**.

## Настройки прокрутки

| Параметр | Что меняет |
|---|---|
| Расстояние прокрутки | Базовое расстояние на один поворот колеса |
| Ускорение при быстром вращении | Дополнительное расстояние при учащённом вращении; 0% выключает бонус |
| Сглаживание серии шагов | Мягкость объединения щелчков; большее значение увеличивает отклик и время остановки |
| Разгон | Скорость набора движения; меньше — быстрее реакция |
| Инерция и остановка | Длительность мягкого торможения |
| Частота обновления | Частота выдачи мелких событий, 60/120/240/500 Гц; не FPS приложения |

Свободное колесо не ограничивается отдельным потолком скорости программы. Итоговая плавность зависит от приложения, дисплея, мыши и нагрузки. Характер движения предлагает сбалансированный и тягучий профили. Изменения действуют сразу и сохраняются автоматически.

## Исключения

«Выбрать из запущенных» открывает отдельное окно с поиском по названию и пути. Можно выбрать несколько программ и добавить их одной кнопкой.

«Выбрать из установленных» открывает стандартный диалог Windows для выбора EXE. Наличие программы в списке установленных Windows не требуется.

Карточка содержит иконку, имя и полный путь. Включённое исключение оставляет программе исходный скролл. Выключенное сохраняется, но не действует. Корзина удаляет запись.

Новые правила сравнивают полный путь без учёта регистра, поэтому разные версии приложения в разных папках независимы. Повторное добавление того же EXE не создаёт дубликат. Старые записи по имени сохраняются с отметкой «Совместимое исключение» и продолжают работать по имени.

Переключатель «Прокрутка в других программах» разрешает/выключает внешний скролл. На этой странице также выбирается системная, светлая или тёмная тема.

## Трей, пауза и выход

Закрытие настроек оставляет Smoove в фоне. Значок находится в области уведомлений Windows и может быть среди скрытых значков. «Настройки» открывает окно, «Сглаживать» включает/выключает обработку, «Выход» завершает программу.

В главном разделе переключатель плавной прокрутки позволяет сравнить исходное и обработанное колесо. Повторный запуск не создаёт второй перехватчик; окно уже работающей программы открывается из трея.

## Если результат неудобен

- Проверьте включение обработки и исключения.
- Слишком медленно: увеличьте расстояние или ускорение. При задержке реакции уменьшите сглаживание/разгон.
- Слишком длинный хвост: уменьшите инерцию или сглаживание.
- Одна программа работает плохо: добавьте её в исключения.
- Повышенные процессы, UAC и защищённые экраны обычно получают исходный ввод. Игры с античитом не заявлены как поддерживаемые.
- Shift + обычное колесо прокручивает горизонтально: вниз — вправо, вверх — влево. Настройки скорости, ускорения, плавности и инерции общие для обеих осей. Отпускание Shift сохраняет горизонтальный хвост. Ctrl/Alt, нажатые кнопки и смена окна отменяют хвост. Движение курсора внутри окна не отменяет прокрутку. Физическое горизонтальное колесо остаётся исходным.

Настройка Windows прокрутки неактивных окон влияет на получателя событий. Утилиты производителя мыши могут отдельно преобразовывать ввод; при конфликте сравните работу с одним преобразователем.

Для GitHub Issues укажите Windows build, программу/версию, модель мыши, параметры Smoove и конкретные действия. Не публикуйте личную переписку и приватные документы.

## Настройки, обновление, удаление

Файл `%LOCALAPPDATA%\Smoove\settings.json` содержит параметры и исключения; рядом сохраняется `.bak`. Всё хранится локально, аккаунт и облачный сервис не нужны.

Для обновления завершите Smoove через трей и запустите новый установщик. Настройки сохраняются. Для удаления завершите процесс и выберите Smoove в «Установленных приложениях» Windows. Чтобы полностью сбросить настройки, отдельно удалите `%LOCALAPPDATA%\Smoove`, когда Smoove завершён.

## Автозапуск и виртуальные рабочие столы

В «Настройках» включите **«Запускать при старте Windows»**, если хотите запускать Smoove при входе в свою учётную запись. Он появляется в трее без окна настроек. Выключение переключателя удаляет автозапуск. Windows может независимо запретить запуск в «Параметры → Приложения → Автозагрузка»; Smoove не отменяет это решение. Установщик переносит действующую регистрацию beta на новую папку, а при удалении снимает регистрацию, если она указывает на удаляемую установку.

При вызове из трея настройки появляются на текущем виртуальном рабочем столе. Если окно было на другом столе, оно пересоздаётся здесь, сохраняя страницу и параметры. Меню трея также открывается на текущем столе.
