# Как пользоваться Smoove

## Первый запуск

Скачайте [установщик Smoove 1.1.0](https://github.com/starkovskypro-code/Smoove-2.0/releases/download/v1.1.0/Smoove-1.1.0-Setup-win-x64.exe), запустите установщик и откройте Smoove.

Библиотеки .NET и Windows App SDK включены в установщик. Сборка предназначена для Windows 11 x64 и не подписана сертификатом издателя.

При обновлении завершите Smoove через «Выход» в трее, запустите новый установщик. Пользовательские настройки в `%LOCALAPPDATA%\Smoove` сохраняются.

При переходе с beta 0.5.0-beta.2 завершите её через трей и распакуйте новую сборку в отдельную папку. Автозапуск при необходимости включите заново в настройках.

Проверьте длинную страницу браузера и привычную переписку. Рекомендуемые настройки: **расстояние 1×, ускорение 60%, сглаживание 110%, частота «Авто»**.

## Настройки прокрутки

Чтобы остановить инерционный хвост, сделайте один щелчок в обратную сторону после небольшой паузы во вращении. Smoove плавно затормозит за 120 мс без обратного перемещения. Следующие щелчки начнут прокрутку в новом направлении. При непрерывном вращении смена направления работает как обычный плавный разворот. Правило действует для вертикали и Shift + колеса.

| Параметр | Что меняет |
|---|---|
| Расстояние прокрутки | Базовое расстояние на один поворот колеса |
| Ускорение при быстром вращении | Дополнительное расстояние при учащённом вращении; 0% выключает бонус |
| Сглаживание серии шагов | Мягкость объединения щелчков; большее значение увеличивает отклик и время остановки |
| Темп анимации | 0,5–8×; масштабирует время всего движения поверх текущих настроек, без увеличения расстояния на щелчок |
| Разгон | Скорость набора движения; меньше — быстрее реакция |
| Инерция и остановка | Длительность мягкого торможения |
| Частота обновления | «Авто» по монитору под курсором или 60/120/240/500 Гц; не FPS приложения. Частота общая для всех профилей |

Свободное колесо не ограничивается отдельным потолком скорости программы. Итоговая плавность зависит от приложения, дисплея, мыши и нагрузки. Характер движения предлагает сбалансированный и тягучий профили. Изменения действуют сразу и сохраняются автоматически.

## Программы: профили и исключения

Профили программ доступны начиная с версии 1.1.0.

«Выбрать из запущенных» открывает отдельное окно с поиском по названию и пути. Можно выбрать несколько программ и добавить их одной кнопкой.

«Выбрать из установленных» открывает стандартный диалог Windows для выбора EXE. Наличие программы в списке установленных Windows не требуется.

Карточка содержит иконку, имя и полный путь. Выберите режим **«Общие настройки»**, **«Свой профиль»** или **«Исключить — стандартное колесо»**. Для своего профиля нажмите **«Настроить»**: откроются обычные ползунки с отдельным выбором движка. В списке **«Настройки для»** можно вернуться к общим значениям. Изменения сохраняются сразу; переключение режима не удаляет ранее настроенный свой профиль. Частота, включение программы и оформление остаются общими.

Выключенная запись сохраняется, но не участвует в выборе. В режиме **«Только в выбранных программах»** сглаживаются только активные записи с общим или своим профилем; остальные получают исходный ввод. Корзина удаляет запись. Изменение режима, движка или списка правил останавливает текущий хвост, чтобы он не попал в другой контекст. Изменение ползунков своего профиля продолжает движение без скачка позиции.

Новые правила сравнивают полный путь без учёта регистра, поэтому разные версии приложения в разных папках независимы. Повторное добавление того же EXE не создаёт дубликат. Старые исключения переносятся в режим «Исключить» с сохранением включения. Записи по имени отмечены как совместимые; активный точный путь имеет приоритет над совместимой записью.

Переключатель «Прокрутка в других программах» разрешает/выключает внешний скролл. Тема выбирается в разделе «Настройки».

## Монитор и терминалы IDE

В режиме **«Авто»** Smoove примерно раз в две секунды получает установленную частоту монитора под курсором и выбирает удвоенную частоту выдачи событий, от 60 до 500 Гц. Например, для 144 Гц это 288 Гц. Если частоту определить не удалось, используется 120 Гц. Это не синхронизация с кадрами или мгновенной частотой VRR и не гарантия меньшей нагрузки. Старые настройки сохраняют выбранную фиксированную частоту.

В Code/Code Insiders, Cursor, Windsurf, VSCodium/Codium, Visual Studio и Rider распознавание UI Automation оставляет терминальной области исходное колесо. Редактор в том же окне продолжает сглаживаться. Распознавание зависит от доступности и разметки UI Automation; если область IDE не удалось подтвердить, ввод временно пропускается. Для неподдерживаемой IDE можно использовать исключение всей программы.

## Трей, пауза и выход

Закрытие настроек оставляет Smoove в фоне. Значок находится в области уведомлений Windows и может быть среди скрытых значков. «Настройки» открывает окно, «Сглаживать» включает/выключает обработку, «Выход» завершает программу.

В главном разделе переключатель плавной прокрутки позволяет сравнить исходное и обработанное колесо. Повторный запуск не создаёт второй перехватчик; окно уже работающей программы открывается из трея.

## Если результат неудобен

В экспериментальной сборке список **«Движок прокрутки»** переключает **Smoove — основной** и **Smoothie — экспериментальная модель**. У каждого свои сохранённые параметры. При переключении хвост останавливается; следующий щелчок обрабатывается выбранной моделью. Старые настройки открываются с основным движком. В экспериментальной модели хвост интегрируется точно: прямое дискретное воспроизведение могло оставлять ненулевой остаток пути при практически нулевой скорости.

Последний участок экспериментального движения плавно доводит скорость до нуля вместо отправки всего малого остатка одним событием. Основная форма серии и усиление расстояния от ускорения/инерции сохранены. Дробные единицы учитываются между жестами, чтобы округление не теряло путь. Это уточнение завершения относительно восстановленной модели конкурента; новые ползунки не требуются.

Экспериментальная модель воспроизводит найденные формулы Smoothie Scroll 1.4.2 на C#, а не запускает его DLL. Её параметры: расстояние 0,5–12×, сглаживание 20–200 мс, ускорение 0–2 и инерция 0–2. Начальные значения конкурента: 8×, 80 мс, 1 и 0,5. Для сравнения уменьшите расстояние до привычного; одинаковые цифры ускорения/инерции у двух моделей не означают одинаковое движение. После паузы обратный щелчок плавно тормозит хвост за 120 мс без обратного перемещения; следующие щелчки начинают движение в новом направлении. Отдельного «Темпа анимации» у этой модели нет. Частота и отправка прокрутки остаются общими для двух вариантов, оба поддерживают горизонтальное колесо. Движок выбирается в общих настройках либо в своём профиле программы.

- Проверьте включение обработки и исключения.
- Нравится характер, но движение затянуто: увеличьте «Темп анимации». Диапазон 0,5–8×; 1× сохраняет прежнее поведение, 2× ускоряет разгон и остановку примерно вдвое, 8× — в восемь раз, без увеличения расстояния на щелчок. Параметр общий для обеих осей и сохраняется автоматически; старые настройки получают 1×.
- При непрерывном вращении темп сокращает задержку и хвост, но не удваивает среднюю скорость: она зависит от поступающего расстояния. Паузы между щелчками остаются реальными, поэтому на высоком темпе пульсации заметнее.
- Изменение темпа на ходу сохраняет позицию и цель, но сразу меняет скорость. Торможение обратным щелчком занимает 120 мс при 1×, 60 мс при 2× и 15 мс при 8×; порог распознавания тормоза остаётся 80 мс реального времени. При разворотах конечная позиция может отличаться: цель зависит от уже пройденного пути.
- Нужно больше расстояния при вращении: увеличьте расстояние или ускорение. При задержке реакции уменьшите сглаживание/разгон.
- Слишком длинный хвост: уменьшите инерцию или сглаживание.
- Одна программа работает плохо: добавьте её в исключения.
- Повышенные процессы, UAC и защищённые экраны обычно получают исходный ввод. Игры с античитом не заявлены как поддерживаемые.
- Shift + обычное колесо прокручивает горизонтально: вниз — вправо, вверх — влево. Физическое горизонтальное колесо тоже сглаживается; направление сохраняется. Настройки активного профиля общие для обеих осей. Отпускание Shift сохраняет горизонтальный хвост. Ctrl/Alt, нажатые кнопки и смена окна отменяют хвост. Движение курсора внутри разрешённой области окна не отменяет прокрутку.

Настройка Windows прокрутки неактивных окон влияет на получателя событий. Утилиты производителя мыши могут отдельно преобразовывать ввод; при конфликте сравните работу с одним преобразователем.

Для GitHub Issues укажите Windows build, программу/версию, модель мыши, параметры Smoove и конкретные действия. Не публикуйте личную переписку и приватные документы.

## Настройки, обновление, удаление

Файл `%LOCALAPPDATA%\Smoove\settings.json` содержит общие настройки, профили программ и исключения (формат версии 5); рядом сохраняется `.bak`. Старые настройки переносятся автоматически. Всё хранится локально, аккаунт и облачный сервис не нужны.

Для обновления завершите Smoove через трей и запустите новый установщик. Настройки сохраняются. Для удаления используйте «Установленные приложения» Windows; пользовательские настройки в `%LOCALAPPDATA%\Smoove` можно удалить отдельно.

## Автозапуск и виртуальные рабочие столы

В «Настройках» включите **«Запускать при старте Windows»**, если хотите запускать Smoove при входе в свою учётную запись. Он появляется в трее без окна настроек. Выключение переключателя удаляет автозапуск. Windows может независимо запретить запуск в «Параметры → Приложения → Автозагрузка»; Smoove не отменяет это решение. Установщик переносит действующую регистрацию beta на новую папку, а при удалении снимает регистрацию, если она указывает на удаляемую установку.

При вызове из трея настройки появляются на текущем виртуальном рабочем столе. Если окно было на другом столе, оно пересоздаётся здесь, сохраняя страницу и параметры. Меню трея также открывается на текущем столе.
